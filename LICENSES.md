# Repository licensing map

This file explains which license applies to each part of opennosh. It is an engineering map, not legal advice.

The combined distribution notice is [`NOTICE.md`](NOTICE.md). It summarizes the required code,
dataset, UI, and export notices without changing any operative terms.

| Material | License | Operative notice |
|---|---|---|
| Original application code, scripts, tests, configuration, and project documentation | MIT | [`LICENSE`](LICENSE) |
| Eligible original community food-pack material under `packs/` | CC0 1.0 Universal | [`packs/LICENSE.md`](packs/LICENSE.md) and [`packs/CC0-1.0.txt`](packs/CC0-1.0.txt) |
| USDA data | Public domain / CC0, as marked at source | Source metadata retained per record |
| Open Food Facts data | ODbL 1.0 database rights and DbCL 1.0 contents rights | Separate store, attribution, and export described in [`04-DATA-LICENSING.md`](04-DATA-LICENSING.md) |
| wger exercise data accepted by v1 | CC BY-SA 3.0 per accepted entry | Separate catalogue, per-entry attribution, and ShareAlike export described in [`04-DATA-LICENSING.md`](04-DATA-LICENSING.md) |

The root MIT license does not relicense community food packs or third-party data. Files carrying a more specific notice follow that notice. Product images from Open Food Facts and wger application code are not included in v1.
