# Security policy

OpenPlate is pre-release and does not yet have supported production versions.

Do not file a normal issue for a suspected vulnerability or exposed credential. While this repository is private, collaborators should create a draft advisory from the repository's Security tab. Before the repository becomes public, the owner must enable GitHub Private Vulnerability Reporting; after that, reporters should use the private [Report a vulnerability](https://github.com/RujitRaval/open-plate/security/advisories/new) form. Include reproduction details, affected versions or commits, impact, and any safe remediation suggestion. Do not include real personal health data.

Develop security fixes in the advisory's private temporary fork. Publish or merge the fix only when coordinated disclosure is ready; do not use a normal public branch or pull request for an undisclosed vulnerability.
