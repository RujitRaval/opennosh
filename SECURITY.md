# Security policy

opennosh is pre-release and does not yet have supported production versions.

Do not file a normal issue for a suspected vulnerability or exposed credential. GitHub Private Vulnerability Reporting is enabled; use the private [Report a vulnerability](https://github.com/RujitRaval/opennosh/security/advisories/new) form. Include reproduction details, affected versions or commits, impact, and any safe remediation suggestion. Do not include real personal health data.

Develop security fixes in the advisory's private temporary fork. Publish or merge the fix only when coordinated disclosure is ready; do not use a normal public branch or pull request for an undisclosed vulnerability.
